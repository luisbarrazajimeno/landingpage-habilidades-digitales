# landingpage-habilidades-digitales

This repository now includes a minimal scaffold for a POS (Point of Sale) system using React and TypeScript. The POS project lives in the `pos-app` directory.

```
landingpage-habilidades-digitales/
├── landingpage/      # Existing landing page files
└── pos-app/          # React + TypeScript POS scaffold
```

Install dependencies in `pos-app` once network access is available and start the development server with `npm run dev`.
